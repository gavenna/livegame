## 错误复盘

1. **没看文档就写适配器** — 可遇AI 用 `msgType` 而非 `type`，数据扁平无嵌套。改了 3 版才对齐。教训: 先读 docs/ 再写代码。
2. **正则批量迁移 logger** — `s.replace()` 把模板字符串 + 相邻单引号字符串全搞断了，手工修了 15+ 处。教训: 不写正则批量改 JS，逐文件改 + `node --check`。
3. **douyin.js logger.init() 纠结** — 忘了独立进程需要自己初始化，反复删除/加回。教训: 改模块前先确认进程模型。
4. **Windows GBK → Pino UTF-8 乱码** — 试了 `setDefaultEncoding` 无效，最终 `chcp 65001` 解决。教训: OS 层面的编码问题要在 OS 层面修。
5. **注意力漂移** — "弹幕看不到" → 跑去重构日志 → 用户说"放狗屁"。教训: [[diagnose-data-flow-first]]

# 使用指南

## 启动

### 一键启动
```powershell
# PowerShell（推荐）
.\start.bat

# Git Bash
bash start.sh
```

### 分步启动（调试用）
```bash
# 终端 1：游戏服务端
node server/index.js

# 终端 2：前端静态服务
npx http-server frontend -p 3000 -c-1

# 终端 3：模拟器
node server/simulator.js
```

浏览器打开 `http://localhost:3000` 看到游戏画面。

## 模拟器指令

启动后输入以下指令控制游戏：

| 指令 | 效果 |
|------|------|
| `join red` 或 `red` 或 `1` | 加入炎龙帝国（红方） |
| `join blue` 或 `blue` 或 `2` | 加入霜狼联盟（蓝方） |
| `gift militia` | 出动 1 名民兵（免费） |
| `gift knight` | 出动 1 名骑士（5 抖币） |
| `gift giant` | 出动 1 名岩石巨人（520 抖币） |
| `gift dragonKnight` | 出动 1 名龙骑士（1200 抖币） |
| `gift wrathOfGod` | 释放天神之怒（3000 抖币） |
| `gift warChest` | 开战争宝箱（99 抖币，随机） |
| `danmaku 杀` | 弹幕"杀"= 3 民兵 |
| `danmaku 冲` | 弹幕"冲"= 全体友军加速 |
| `danmaku 任意文本` | 普通弹幕，显示在画面底部 |
| `status` | 查看连接状态 |
| `help` | 显示帮助 |
| `exit` | 退出 |

### 可用兵种 key

`militia` `swordsman` `knight` `archer` `catapult` `royalGuard` `giant` `dragonKnight` `wrathOfGod` `warChest`

## 日志系统

### 开关控制

在 `server/config.js` 的 `LOG` 块里按需开关：

```js
LOG: {
  LEVEL: 'DEBUG',       // 全局级别: DEBUG | INFO | WARN | ERROR
  TAGS: {
    WS: true,           // WebSocket 连接
    ENGINE: true,       // 游戏状态机
    BATTLE: true,       // 战斗计算（高频，可关）
    DANMAKU: true,      // 弹幕处理
    RANKING: true,      // 积分/排行
    GIFT: true,         // 礼物处理
    SERVER: true,       // 服务器启动
    SIMULATOR: true,    // 模拟器
  },
  TO_FILE: true,        // 写文件
  TO_CONSOLE: true,     // 终端输出
},
```

- 关掉某个 tag → 该类型的日志不再出现
- `LEVEL: 'WARN'` → 只显示 WARN 和 ERROR
- 战斗层高频日志不刷屏，只记关键事件

### 日志文件

每次启动在 `server/logs/` 下生成：
- `session-YYYYMMDD-HHmmss.log` — 当次会话完整日志
- `error.log` — 所有 ERROR 级别日志汇集

## 出了 bug 怎么查

### 标准流程

1. **看 error.log** — 有没有直接报错？先搜 `[ERROR]`
2. **没问题 → 定位层**：
   - 弹幕没反应？ → 开 `DANMAKU: true`，看日志有没有收到指令
   - 兵种不动？ → 开 `BATTLE: true`，看 tick 里的数据
   - 积分没变？ → 开 `RANKING: true`，看结算逻辑
   - 前端不显示？ → 开 `WS: true`，看广播数据
3. **日志不够细** → 把 `LEVEL` 设为 `DEBUG`，重现一次
4. **日志看不出** → 在怀疑的节点加 `assert()`，逐个用断言定位
5. **找到根因** → 修 → 补日志 → 写 `docs/bugs/` 沉淀

### 常见问题

**Q: 改了 config.js 不生效？**  
A: 需要重启 server。config 不热更新。

**Q: OBS 看到的是旧画面？**  
A: OBS 浏览器源有独立缓存。右键浏览器源 → 刷新。

**Q: 模拟器连不上 server？**  
A: 确认端口 8765 没被占用。`netstat -ano | findstr 8765`。

**Q: 端口被占用怎么杀？**  
A: `netstat -ano | findstr 8765` 找到 PID → `taskkill /PID <pid> /F`。
